# 📚 StudyFlow – HTML Study Planner Dashboard

A front-end **HTML / CSS / JavaScript** project that acts as a lightweight study planner for students.

This is a great GitHub portfolio project to show:

- Clean, responsive UI
- Vanilla JavaScript state management
- LocalStorage persistence
- Filtering, stats, and simple UX logic

---

## ✨ Features

- Add tasks with:
  - Title
  - Course name
  - Due date
  - Priority (low, medium, high)
  - Optional notes
- Filter tasks by:
  - Course
  - Status (pending / done)
  - Priority
- See quick stats:
  - Total tasks
  - Completed tasks
  - High priority tasks
  - Tasks due this week
- “Today” panel:
  - Shows tasks due today
  - Highlights the course you’re most busy with
- All data is stored in **localStorage** in the browser (no backend).

---

## 🧱 Tech Stack

- HTML5
- Modern CSS (no frameworks)
- Vanilla JavaScript
- LocalStorage for persistence

---

## ▶️ How to Run

1. Clone or download this repo.
2. Open `index.html` in any modern browser (Chrome, Edge, Firefox, Safari).
3. Start adding tasks – they will automatically be saved to your browser.

You can also host it on **GitHub Pages** by:

- Pushing this folder to a GitHub repo
- Enabling Pages (branch: `main`, folder: `/root`)
